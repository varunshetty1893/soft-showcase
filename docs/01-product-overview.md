# 01 — Product Overview

## Platform Name

**Soft Showcase**

The number **11** is the founder's lucky number and is intentional.

---

## Vision

Soft Showcase is a **professional software-project discovery and lead-generation platform**.

The platform exists to bridge the gap between software project creators (providers) and potential buyers or collaborators (visitors/customers).

---

## Mission

Make it easy for:

1. **Visitors** to discover, understand, and contact project providers about software projects.
2. **Providers** to showcase their work professionally and receive qualified leads.
3. **Administrators** to manage the platform, projects, and providers efficiently.

---

## What Soft Showcase Is

| Aspect | Description |
|---|---|
| Type | Project catalog + lead generation platform |
| Primary action | Visitor contacts provider via WhatsApp or Email |
| Secondary action | Visitor submits custom project request |
| Commerce | No online payment in V1 |
| Commission | No commission in V1 |
| Discovery | Visitors browse by category, technology, type, etc. |

---

## What Soft Showcase Is NOT

- Not an e-commerce store
- Not a marketplace with checkout
- Not a freelancing platform (like Upwork)
- Not a commission-based platform in V1
- Not a SaaS subscription service

---

## Core Value Proposition

### For Visitors / Customers

- Discover real, deployable software projects
- Understand exactly what each project includes
- View live demos and screenshots
- Contact the project creator directly
- Request customizations through the provider

### For Providers

- Showcase projects professionally
- Receive qualified leads (people already interested in their project)
- Maintain independent contact details
- No upfront costs or commissions in V1

### For Administrators

- Manage the entire platform
- Import project data easily via JSON
- Manage multiple providers independently
- Track inquiries and communication

---

## Platform Differentiators

1. **Provider-centric architecture** — Each project has its own assigned provider with independent contact information.
2. **AI-assisted import** — Admin can ask an AI to generate structured project JSON, then paste and import.
3. **WhatsApp-first communication** — Optimized for markets where WhatsApp is primary business communication.
4. **Privacy-respecting email flow** — Provider emails are never exposed; customer contacts through a form.
5. **Lead capture** — Every inquiry is stored and manageable.

---

## Target Market

- Software developers with projects to sell or license
- Project aggregators managing multiple developer products
- Boutique software agencies
- Independent developers building niche tools
- Regional markets where WhatsApp business communication is common

---

## V1 Scope

**Included in V1:**

- Project catalog with search and filters
- Project detail pages
- Provider management (admin only)
- WhatsApp contact flow
- Email inquiry form and routing
- Custom project request form
- Project JSON import
- Admin dashboard
- Google OAuth authentication
- Inquiry management

**Explicitly NOT in V1:**

- Online payment / checkout
- Commission tracking
- Provider payout
- Provider login accounts
- Live chat
- Marketplace wallet
- Subscription pricing
- Review/rating system
